# Echo Hanzi · 中文打字学习器

受 [echo-type.app](https://echo-type.app/) “用打字练语言”的思路启发，做成面向**中文学习者**（HSK 1–2 起步）的打字训练器：看到汉字/释义 → 打出拼音 → 即时校对 → 听到发音。

**零依赖、零构建**：纯 HTML + CSS + 原生 JS，双击 `index.html` 就能用。

---

## 一、快速开始

```bash
# 方式 A：直接打开
open index.html

# 方式 B：本地服务器（推荐，语音/本地存储行为更稳定）
./serve.sh          # 或 bash serve.sh 8765
# -> http://127.0.0.1:8765/
```

> 需要 `python3`（macOS 自带）。第一次输入或点击页面时会请求焦点，输入框是隐藏的，只负责接管键盘。

## 二、已经实现的功能

| 能力 | 说明 |
| --- | --- |
| 词模式 / 句模式 | 词模式练单个词（大字号汉字）；句模式练整句，汉字逐字点亮，像卡拉 OK 字幕 |
| 拼音打字判题 | 逐字母比对，正确的字母变亮、错误的字母红色抖动；支持退格回退 |
| 标点键位 | 句模式中 `，。！？` 要按真实输入法习惯敲 `,` `.` `!` `?`，键帽会提示该按哪个 |
| 声调训练模式 | 开关“声调”后需输入声调数字：`ma1 ma5`，把四声变成肌肉记忆 |
| 听音模式（Echo） | 隐藏汉字与拼音，只给英文释义 + 发音；打对后才揭示答案，逼你“听音—回忆—输出” |
| 普通话朗读 | Web Speech API（zh-CN），可开关；完成一个词自动读一遍 |
| 连写音节切分 | `huǒchēzhàn` → `huo3 che1 zhan4`，词库不必严格空格，也支持 `nǚ'ér` |
| ü 双写兼容 | `nǚ` 打 `nv` 或 `nu` 都算对 |
| 实时数据 | 字符/分（CPM）、正确率、连击、计时，进度条 |
| 成绩页 | 本轮 CPM / 正确率 / 词数 / 最长连击 + **需要复习的词表**（点一下重听发音） |
| 词库切换 | HSK 1（150 词）/ HSK 2（148 词）/ 合并（298 词）；句库 40 句（HSK 1 20 句 / HSK 2 20 句），每轮 10 / 20 / 50 / 全部 |
| 偏好持久化 | 主题、词库、模式、音量等存 localStorage |
| 键盘快捷键 | `Tab` 换词 · `Esc` 重来 · `?` 看答案 · 空格自动跳过（为真实输入法留位） |
| 响应式 | 320px 起可用；暗/亮主题跟随手动切换 |

## 五、怎么扩充词库

编辑 `data.js`，一行一个词：

```js
['火车站', 'huǒchēzhàn', 'train station'],
['女儿',   "nǚ'ér",       'daughter'],
```

* 拼音写**带声调符号**的版本即可，音节之间加不加空格都可以（内部会自动切分）。
* 轻声不标调（`yīfu` 的 `fu`），声调模式下要求输入 `5`。
* 想加 HSK 3 或专业词汇，新建一个数组并在 `LISTS` 里注册：

```js
var HSK3 = [ /* ... */ ];
LISTS.hsk3 = toObjects(HSK3, 'HSK 3');
```
再在 `index.html` 的下拉框里加一个 `<option value="hsk3">HSK 3</option>`。

### 加句子

编辑 `data.js` 里的 `SENTENCES`：

```js
['我喜欢喝茶。', 'wǒ xǐhuan hē chá。', 'I like drinking tea.', 'hsk1'],
```

* 拼音**逐字分隔**（一个字一个音节），汉字标点直接写全角 `，。！？`，与汉字一一对应。
* 数据守则：非标点汉字数 **必须等于** 音节数，否则 `tests/` 会报 `COUNT` 错误。写完跑一次 `./tests/run.sh` 或下面的自检即可。

## 六、下一步路线（按优先级）

1. **SRS 复习排程**：把“需要复习的词/句”真正记下来，第二天优先推送（对齐 Anki 的间隔重复）。
2. **内建输入法候选框**：不依赖系统 IME，自己弹 1/2/3 候选词，彻底解决 `compositionstart` 冲突。
3. **汉字笔顺动画**：接入 `hanzi-writer`（需要引 CDN 或本地打包）做部首/笔顺提示。
4. **双拼 / 五笔训练**：为母语者进阶准备（小鹤、自然码、86 五笔），复用同一套判题引擎。
5. **数据看板**：历史 CPM 曲线、易错音（`zh/ch/sh`、`n/l`、声调）热力图。
6. **PWA 离线**：加 manifest + service worker，可安装到桌面/手机主屏。

## 七、实现取舍备注

* **不做真实 IME 拦截**：浏览器里劫持中文输入法的 composition 事件在跨平台下极其脆弱，所以采用“打拼音字母（+ 声调数字）”的判题模型，判定完全可控，也顺便练了拼写。
* **音效全部合成**：不引入音频资源，Web Audio 现场生成，包体为 0。
* **纯静态无构建**：换语言/换词库只改 `data.js`；后续要上 Next.js 做 SEO 落地页时，这套引擎（`pinyin.js` + 判题逻辑）可以原样搬走。
